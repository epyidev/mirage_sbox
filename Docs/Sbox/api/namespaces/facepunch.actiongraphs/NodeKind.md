# Facepunch.ActionGraphs.NodeKind

Nodes can be lazily evaluated expression without any signals,
or actions that execute when receiving a signal.

- **Kind:** enum
- **Namespace:** `Facepunch.ActionGraphs`
- **Assembly:** `Facepunch.ActionGraphs`
- **Base:** `System.Enum`

## Values

- `Expression` - A lazily evaluated node without any signals.
- `Action` - A node that performs an action when receiving an input signal.
