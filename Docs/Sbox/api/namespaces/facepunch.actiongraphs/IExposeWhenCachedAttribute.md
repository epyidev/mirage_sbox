# Facepunch.ActionGraphs.IExposeWhenCachedAttribute

Declares that instances of the marked type can't be cached in a `Facepunch.ActionGraphs.ActionGraphCache`.
For example, if they might contain an ID that needs to get fixed up post serialization.

- **Kind:** interface
- **Namespace:** `Facepunch.ActionGraphs`
- **Assembly:** `Facepunch.ActionGraphs`
