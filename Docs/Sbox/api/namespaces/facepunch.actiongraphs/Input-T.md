# Facepunch.ActionGraphs.Input<T>

Helper type for input parameters of methods marked with `Facepunch.ActionGraphs.NodeAttribute`.
The value of this input can be evaluated on demand, for cases where it may change during the
invocation of the node.

- **Kind:** sealed class
- **Namespace:** `Facepunch.ActionGraphs`
- **Assembly:** `Facepunch.ActionGraphs`

## Properties

- `T Value`
  - Evaluate this input.
