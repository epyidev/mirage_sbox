11 types.

- [`MapEntity`](./MapEntity.md) - MapEntity in Hammer is a type of `Editor.MapDoc.MapNode` that has a set of key/value pairs.
- [`MapGameObject`](./MapGameObject.md)
- [`MapGroup`](./MapGroup.md) - A map node which has the sole purpose of grouping other map nodes together.
- [`MapInstance`](./MapInstance.md) - A map node which allows a target group and its children to be placed with a new position
- [`MapMesh`](./MapMesh.md) - MapMesh is the Hammer map node which represents editable mesh geometry in a Hammer map.
- [`MapNode`](./MapNode.md) - A common class used for all objects in the world object tree.
- [`MapPath`](./MapPath.md) - Path containing a bunch of `Editor.MapDoc.MapPathNode`
- [`MapPathNode`](./MapPathNode.md) - Nodes along a `Editor.MapDoc.MapPath`
- [`MapStaticOverlay`](./MapStaticOverlay.md) - An overlay which is rendered using a mesh generated by projecting faces onto
- [`MapWorld`](./MapWorld.md) - MapWorld is the root node of a `Editor.MapDoc.MapDocument`, however it can have multiple sub `Editor.MapDoc.MapWorld` of prefabs.
