# Sandbox.ModelEditor.CylinderAttribute

Draws a cylinder, which can be manipulated via gizmos. You can have multiple of these.

- **Kind:** attribute
- **Namespace:** `Sandbox.ModelEditor`
- **Assembly:** `Sandbox.Engine`
- **Base:** `Sandbox.ModelEditor.CapsuleAttribute`

## Constructors

- `CylinderAttribute(System.String point1Key, System.String point2key, System.String radiusKey)`
  - This variation has 1 radius for both points.
- `CylinderAttribute(System.String point1Key, System.String point2key, System.String radius1Key, System.String radius2Key)`
  - This variation has independent radius for each point.
