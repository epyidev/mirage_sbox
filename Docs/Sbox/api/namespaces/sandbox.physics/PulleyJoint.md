# Sandbox.Physics.PulleyJoint

A pulley constraint. Consists of 2 ropes which share same length, and the ratio changes via physics interactions.
            
Typical setup looks like this:


```

   @-----------------@
   |                 |
   |                 |
Object A          Object B

```
