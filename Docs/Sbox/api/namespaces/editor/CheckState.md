# Editor.CheckState

Check state of a `Editor.Checkbox`.

- **Kind:** enum
- **Namespace:** `Editor`
- **Assembly:** `Sandbox.Tools`
- **Base:** `System.Enum`

## Values

- `Off` - The checkbox is not checked.
- `Partial` - Partial. This is useful in cases when representing multiple objects,
with a boolean value where some are set to true, and others to false.
- `On` - The checkbox is checked.
