# Editor.FocusMode

- **Kind:** enum
- **Namespace:** `Editor`
- **Assembly:** `Sandbox.Tools`
- **Base:** `System.Enum`

## Values

- `None` - Do not accept focus.
- `Tab` - Accept focus by tabbing.
- `Click` - Accept focus by being clicked on.
- `TabOrClick` - Accept focus by clicking or tabbing.
- `TabOrClickOrWheel` - Accept focus when using the mouse wheel too.
