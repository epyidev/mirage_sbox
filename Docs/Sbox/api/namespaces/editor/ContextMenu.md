# Editor.ContextMenu

Identical to Menu except DeleteOnClose defaults to true.
Can optionally be made searchable by setting `Editor.ContextMenu.Searchable` to true before opening.

- **Kind:** class
- **Namespace:** `Editor`
- **Assembly:** `Sandbox.Tools`
- **Base:** `Editor.Menu`

## Constructors

- `ContextMenu(Editor.Widget parent)`

## Properties

- `System.Boolean Searchable`
  - Adds a search bar in the context menu. Useful for big menus
