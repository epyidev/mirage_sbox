# Sandbox.SteamId.AccountTypes

The different types of Steam accounts.

- **Kind:** enum
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.System`
- **Base:** `System.Enum`
- **Declaring type:** `Sandbox.SteamId`

## Values

- `Invalid` - Invalid or uninitialized account
- `Individual` - Single user account
- `Multiseat` - Multiseat account (e.g. cybercafe)
- `GameServer` - Game server account
- `AnonGameServer` - Anonymous game server account
- `Pending` - Pending account
- `ContentServer` - Content server account
- `Clan` - Steam group/clan
- `Lobby` - Game lobby
- `ConsoleUser` - Console user (PSN/Xbox Live)
- `AnonUser` - Anonymous user
