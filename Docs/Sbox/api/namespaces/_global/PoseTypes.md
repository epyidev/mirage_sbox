# Sandbox.VR.VRTrackedObject.PoseTypes

The type of pose to track from the controller

- **Kind:** enum
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`
- **Declaring type:** `Sandbox.VR.VRTrackedObject`

## Values

- `Grip` - The grip pose - centered on the palm/grip of the controller.
Best for representing where the hand is holding the controller.
- `Aim` - The aim pose - pointing forward from the controller.
Best for aiming, pointing, or ray casting.
