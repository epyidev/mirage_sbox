# Sandbox.VR.VRTrackedObject.TrackingTypes

Represents transform values to update

- **Kind:** enum
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`
- **Declaring type:** `Sandbox.VR.VRTrackedObject`

## Values

- `None` - Don't update the position or the rotation
- `Rotation` - Update the rotation only
- `Position` - Update the position only
- `All` - Update both the position and rotation
