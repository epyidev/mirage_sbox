# Sandbox.Mapping.Button.ButtonMode

The button's behavior mode.

- **Kind:** enum
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`
- **Declaring type:** `Sandbox.Mapping.Button`

## Values

- `Toggle` - Normal toggle button - click to turn on, click again to turn off.
- `Continuous` - Button is only on while being held down.
- `Immediate` - Button briefly turns on then immediately off when pressed.
