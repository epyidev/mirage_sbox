# TitleAttribute

Sets the title or a "nice name" of a type or a type member.
This info can then be retrieved via DisplayInfo library.

- **Kind:** attribute
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.System`
- **Base:** `System.Attribute`
