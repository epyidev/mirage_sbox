# Sandbox.Package.PackageUsageStats

Statistics for user interactions with this package

- **Kind:** struct
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.Engine`
- **Declaring type:** `Sandbox.Package`

## Properties

- `Sandbox.Package.PackageUsageStats.Group Total`
  - Total lifetime usage stats
- `Sandbox.Package.PackageUsageStats.Group Month`
  - Usage for the last 3 days
- `Sandbox.Package.PackageUsageStats.Group Week`
  - Usage for the last week
- `Sandbox.Package.PackageUsageStats.Group Day`
  - Usage for the last 24 hours
- `System.Int64 UsersNow`
  - How many users are using it right now
- `System.Double Trend`
  - The trend is a number that represents whether it's been popular recently. Higher means more popular.
