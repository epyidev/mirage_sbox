# Sandbox.SceneModel.AnimTagStatus

Enumeration that describes how the AnimGraph tag state changed. Used in `Sandbox.SceneModel.AnimTagEvent`.

- **Kind:** enum
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`
- **Declaring type:** `Sandbox.SceneModel`

## Values

- `Fired` - Tag was activated and deactivated on the same frame
- `Start` - The tag has become active
- `End` - The tag has become inactive
