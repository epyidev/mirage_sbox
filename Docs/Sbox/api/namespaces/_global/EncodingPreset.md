# Sandbox.VideoWriter.EncodingPreset

Controls the speed/quality tradeoff of video encoding.

- **Kind:** enum
- **Namespace:** `(global)`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`
- **Declaring type:** `Sandbox.VideoWriter`

## Values

- `Fast` - Optimized for speed. Suitable for real-time recording.
- `Balanced` - Balanced speed and quality.
- `Quality` - Optimized for quality. Suitable for offline export.
