# Editor.MapEditor.SelectMode

- **Kind:** enum
- **Namespace:** `Editor.MapEditor`

## Values

- `Groups` - Select groups, ungrouped entities, and ungrouped solids
- `Objects` - Select entities and solids not in entities
- `Meshes` - Select point entities, solids in entities, solids
- `Verticies` - Select vertices
- `Edges` - Select edges
- `Faces` - Select faces
- `Nav` - Select nav mesh components
- `Tiles` - Select the grid tiles
