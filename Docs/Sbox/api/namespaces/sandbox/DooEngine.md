# Sandbox.DooEngine

System that manages the execution of Doo scripts within a scene.

- **Kind:** class
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.Engine`
- **Base:** `Sandbox.GameObjectSystem<T>`

## Constructors

- `DooEngine(Sandbox.Scene scene)`
  - Creates a new DooEngine for the given scene.

## Methods

### Instance methods

- `System.Void SetGlobalVariable(System.String name, System.Object value)`
  - Sets a global variable that is accessible to all Doo scripts in this scene.
