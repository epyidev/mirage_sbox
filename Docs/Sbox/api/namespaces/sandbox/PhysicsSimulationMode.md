# Sandbox.PhysicsSimulationMode

Physics simulation mode. For use with `Sandbox.PhysicsWorld.SimulationMode`.

- **Kind:** enum
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`

## Values

- `Discrete` - Discrete collision detection.
In this mode physics bodies can fly through thin walls when moving very quickly, but it is has better performance.
- `Continuous` - Continuous collision detection. This is the default mode.
