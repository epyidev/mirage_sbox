# Sandbox.AssetTypeFlags

Flags for `Sandbox.AssetTypeAttribute`

- **Kind:** enum
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`

## Values

- `None`
- `NoEmbedding` - If set then this resource cannot be embedded. This means that in the editor
it can only really exist as an asset file on disk, not inside another asset.
- `IncludeThumbnails` - Include thumbnails when publishing as part of another package
