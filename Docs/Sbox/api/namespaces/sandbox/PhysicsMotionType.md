# Sandbox.PhysicsMotionType

Represents <see cref="T:Sandbox.PhysicsBody">Physics body's</see> motion type.

- **Kind:** enum
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`

## Values

- `Invalid` - Invalid type.
- `Dynamic` - Physically simulated body.
- `Static` - Cannot move at all.
- `Keyframed` - No physics simulation, but can be moved via setting position/rotation.
