# Sandbox.Preferences

Holds information about the current user's preferences.

- **Kind:** static class
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.Engine`

## Properties

- `static System.Single FieldOfView`
  - The user's preference for their field of view
- `static System.Single MusicVolume`
  - The user's preferred Music volume, as set in the options, clamped between 0 and 1
- `static System.Single VoipVolume`
  - The user's preferred VOIP volume, as set in the options, clamped between 0 and 1
- `static System.Single Sensitivity`
  - The mouse sensitivity
- `static System.Single ControllerLookYawSpeed`
- `static System.Single ControllerLookPitchSpeed`
- `static System.Boolean InvertMousePitch`
- `static System.Boolean InvertMouseYaw`
