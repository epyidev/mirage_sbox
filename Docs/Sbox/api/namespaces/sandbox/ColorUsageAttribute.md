# Sandbox.ColorUsageAttribute

When applied to a Color property, allows you to specify whether the color should have an alpha channel and/or be in HDR.

- **Kind:** attribute
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.System`
- **Base:** `System.Attribute`

## Constructors

- `ColorUsageAttribute(System.Boolean hasAlpha, System.Boolean isHDR)`

## Properties

- `System.Boolean HasAlpha`
- `System.Boolean IsHDR`
