# Sandbox.SceneSpotLight

A simple spot light scene object for use in a `Sandbox.SceneWorld`.

- **Kind:** sealed class
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.Engine`
- **Base:** `Sandbox.SceneLight`

## Constructors

- `SceneSpotLight(Sandbox.SceneWorld world, Vector3 position, Color color)`
- `SceneSpotLight(Sandbox.SceneWorld world)`

## Properties

- `System.Single ConeInner`
  - The inner cone of the spotlight, in half angle degrees.
- `System.Single ConeOuter`
  - The outer cone of the spotlight, in half angle degrees
- `System.Single FallOff`
