# Sandbox.MouseButtons

State of mouse buttons being pressed or not.

- **Kind:** enum
- **Namespace:** `Sandbox`
- **Assembly:** `Sandbox.Engine`
- **Base:** `System.Enum`

## Values

- `None` - No buttons are being pressed.
- `Left` - Left mouse button is being pressed.
- `Right` - Right mouse button is being pressed.
- `Middle` - Middle mouse button (mouse wheel) is being pressed in.
- `Back` - The "back" mouse button (mouse4) being pressed in.
- `Forward` - The "forward" mouse button (mouse5) being pressed in.
