# Sandbox.UI.Wrap

Possible values for `flex-wrap` CSS property.

- **Kind:** enum
- **Namespace:** `Sandbox.UI`
- **Assembly:** `Sandbox.System`
- **Base:** `System.Enum`

## Values

- `NoWrap` - Elements will be laid out in a single line.
- `Wrap` - Elements will be moved to subsequent lines on overflow.
- `WrapReverse` - Same as `Sandbox.UI.Wrap.Wrap`, but the line order will be reversed, i.e. if one item overflows the width,
it will be placed on the first line, and the others will be placed on the second line.
