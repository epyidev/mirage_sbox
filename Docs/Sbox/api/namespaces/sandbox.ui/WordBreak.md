# Sandbox.UI.WordBreak

Possible values for `word-break` CSS property.

- **Kind:** enum
- **Namespace:** `Sandbox.UI`
- **Assembly:** `Sandbox.System`
- **Base:** `System.Enum`

## Values

- `Normal` - Break overflowing lines at the closest word.
- `BreakAll` - Break overflowing lines at the closest character.
