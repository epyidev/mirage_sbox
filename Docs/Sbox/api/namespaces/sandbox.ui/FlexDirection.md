# Sandbox.UI.FlexDirection

Possible values for `flex-direction` CSS property.

- **Kind:** enum
- **Namespace:** `Sandbox.UI`
- **Assembly:** `Sandbox.System`
- **Base:** `System.Enum`

## Values

- `Column` - A column, align items from top to bottom.
- `ColumnReverse` - A reverse column, align items from bottom to top.
- `Row` - A row, align items from left to right.
- `RowReverse` - A reverse row, align items from right to left.
