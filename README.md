<h1 align='center'>Mirage</h1>
<p align='center'><a href='#'>Discord</a> - <a href='#'>Website</a></p>

<p align='center'><b>Custom roleplay gamemode for the <a href='#'>Mirage</a> server on s&box. Inspired by FiveM RP servers, the project layers all the RP logic, the custom UI, and the server-specific systems on top of Facepunch's official <a href='https://github.com/Facepunch/sandbox'>Sandbox</a> game.</b></p>

## Vision

The project is in early development. The long-term goal:

- **RP identity**: first name, last name, job, ID papers, persistent character sheet
- **Economy**: bank and cash money, transfers, jobs, player-run shops
- **Jobs and factions**: police, paramedic, mechanic, gangs, whitelist
- **Vehicles**: purchase, garages, license plates, mechanical condition
- **Properties**: housing purchase or rent, lockers, shared access
- **RP inventory**: roleplay items (keys, phone, papers, drugs, etc.) on top of the sandbox weapons
- **Phone**: SMS, calls, ads, custom apps
- **RP chat**: OOC and IC, distance-based propagation, radios
- **Admin tools**: staff utilities, logs, sanctions, tickets

Not everything ships at once. We build it brick by brick.

## Technical base

The project is built on top of the source code of the official **Sandbox** game by Facepunch ([Facepunch/sandbox](https://github.com/Facepunch/sandbox)), released under the MIT license. The useful base is kept (players, weapons, physics, spawn menu, undo, save system, NPCs, etc.) and the RP logic is layered on top.

The architecture is documented in [CLAUDE.md](CLAUDE.md): s&box Components and Scene model, host-authoritative networking, `Local.IPlayerEvents` and `Global.IPlayerEvents` event interfaces, `GameObjectSystem<T>` singletons, etc.

## Build

No CLI build. s&box compiles from the editor.

1. Open the **s&box** editor.
2. Add this folder as a project (`mirage.sbproj`).
3. Run the `scenes/sandbox.scene` scene.

`*.csproj`, `*.sln`, `obj/`, `bin/`, `.sbox/` are all generated by the editor and ignored by git. Do not commit them.
